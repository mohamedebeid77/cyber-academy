## Terminal sessions

Two kinds, honestly labeled on every page:

- **Real captures** (`ping`, `curl`, `nslookup`, `arp-scan`): output captured on the author's own
  machine during development, presented as-is.
- **Documentation sessions** (the remaining CLI tools): sessions rendered from the command
  examples published in each tool's official documentation / man pages. The rendering is this
  project's; the commands and output format are the projects'. These are teaching aids for
  reading real output, not claims of a specific capture.

## Removed images

Old netcat/curl/ping/tcpdump/objection/lldb captures were removed in favor of the sessions above
and in-lesson terminal blocks.
